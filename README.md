# WiFi Signali Analizer

Коротко
- Скрипт `WiFi_signal_analisator.py` — інструмент для збору та аналізу Wi‑Fi сигналів (пакетів, рівнів сигналу, статистики).

Особливості
- Захоплення пакетів Wi‑Fi (якщо доступ до мережевого інтерфейсу дозволяє)
- Збір статистики RSSI/рівня сигналу по часу
- Збереження результатів у файл для подальшого аналізу

Вимоги
- Python 3.8 або новіше
- Доступ до мережевого інтерфейсу (можливо знадобляться права адміністратора/root)
- Рекомендовані пакети (залежить від реалізації скрипта): `scapy`, `numpy`, `pandas`, `matplotlib`

Встановлення залежностей
Якщо в проєкті є `requirements.txt`, виконайте:

```bash
pip install -r requirements.txt
```

Запуск
Простий приклад запуску (замість `<interface>` підставте назву вашого інтерфейсу):

```bash
python WiFi_signal_analisator.py
# або з аргументами (якщо скрипт їх підтримує):
python WiFi_signal_analisator.py --interface <interface> --duration 60 --output results.csv
```

Поради
- На Windows може знадобитися встановити додаткові драйвери або запуск від імені адміністратора.
- На Linux для захоплення Wi‑Fi пакетів інтерфейс має бути у режимі монітора.
- Перегляньте початок файлу `WiFi_signal_analisator.py`, щоб дізнатися про підтримувані аргументи та опції.
